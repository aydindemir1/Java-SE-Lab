# Interview & Reasoning Questions — Java Fundamentals

1. JDK ile JVM arasındaki fark nedir?
2. Java source code doğrudan CPU'da mı çalışır?
3. Java pass-by-value mı pass-by-reference mı?
4. Primitive type ile reference type arasındaki temel fark nedir?
5. `==` ve `equals` arasındaki fark nedir?
6. Widening ve narrowing conversion nedir?
7. Integer overflow olduğunda Java ne yapar?
8. `&&` ile `&` arasında boolean expression bağlamında ne fark vardır?
9. Local variable'lar neden default initialize edilmez?
10. Array neden object sayılır?
11. String neden immutable tasarlanmıştır?
12. `var` dynamic typing midir?
13. switch expression ile klasik switch arasındaki fark nedir?
14. Java method overloading compile-time mı runtime mı çözülür?
15. Bir Java programını compile etmek ile run etmek arasında hangi adımlar vardır?

## Derin reasoning

- Java pass-by-reference olsaydı mevcut method semantiği nasıl farklı olurdu?
- Numeric overflow'un exception üretmemesi hangi tür production bug'larına yol açabilir?
- Bir API'de `int` yerine `Integer` seçmek memory ve nullability açısından ne değiştirir?

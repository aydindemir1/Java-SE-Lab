# Exercises — Java Fundamentals

## Junior

1. Celsius → Fahrenheit dönüştürücü yaz.
2. Üç sayının en büyüğünü bulan program yaz.
3. Bir sayının tek/çift olduğunu kontrol et.
4. 1–100 arasındaki 3 ve 5'in katlarını yazdır.
5. Bir integer array'in toplamını ve ortalamasını hesapla.

## Mid

6. Overflow oluşturan bir örnek yaz ve `Math.addExact` ile güvenli hale getir.
7. `==` ile `equals` farkını String örneğiyle göster.
8. Java'nın pass-by-value olduğunu ispatlayan üç farklı deney yaz.
9. switch expression kullanarak HTTP status → category dönüştürücü yaz.
10. Command-line argument üzerinden basit hesap makinesi yaz.

## Senior

11. Yan etkili expression içeren kötü bir kodu refactor et.
12. Primitive conversion nedeniyle veri kaybı oluşturan üç vaka üret.
13. Array covariance nedeniyle `ArrayStoreException` oluşturan örnek yaz ve nedenini açıkla.
14. Input validation'ı methodlara ayırarak küçük bir pricing engine yaz.

## Expert

15. String concatenation içeren basit bir sınıfı derle ve `javap -c` ile bytecode'u incele.
16. Boxing/unboxing olan ve olmayan iki örneği bytecode düzeyinde karşılaştır.
17. `switch` statement ve switch expression için bytecode çıktısını karşılaştır.

## Staff / Principal / Architect

18. Bir public Java API'de primitive mi wrapper mı kullanılacağını gerekçelendir.
19. Finansal hesaplama API'sinde `double` seçiminin risklerini analiz et.
20. Bir ekip kod standardında `var` kullanım kurallarını tanımla ve trade-off'larını açıkla.
